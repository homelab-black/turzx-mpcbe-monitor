# turzx-mpcbe-monitor
TURZX 3.5 インチのUSBモニタに MPC-BE 音楽再生時の情報を表示させるためのツールです。

turing-smart-screen-python のライブラリを使っています。

https://github.com/mathoudebine/turing-smart-screen-python/tree/main


## 使い方
### MPC-BE は ウェブインタフェース を有効にする
ファイル → Option → プレーヤー → ウェブインタフェース
以下の2つの項目を有効にする
- 「待機するポート」
- 「ローカルホストからの接続のみ」

### TURZX は縦置きを想定

### 実行方法
python main.py

### その他
動作内容は以下の通りです。
1. MPC-BE のウェブサーバにアクセスして以下の情報を取得
   - 再生中のファイルのフルパス
   - 曲の長さ
   - 再生中の位置
3. 取得した情報の中に開いているファイルのフルパスを取得
4. ファイルのタグ情報から以下の情報取得
   - タイトル
   - アーティスト
   - アルバム
   - オーディオ情報
   - 画像情報
5. 画像情報がない場合は再生ファイルと同一ディレクトリに *cover.* のような画像ファイルを検索
6. それでも画像がない場合は default_png 配下の画像からランダムに抽出
   現状含まれているファイル AI で生成した画像となっています。
   - 落ち着いた雰囲気の風景画
   - 落ち着いた雰囲気の未来都市
   - 落ち着いた雰囲気の宇宙
5. 各種情報を 3.5インチの画面に表示
   基本的には MPC-BE で音楽を再生しているイメージと似た雰囲気になります。
