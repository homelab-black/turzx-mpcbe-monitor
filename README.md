# turzx-mpcbe-monitor
TURZX 3.5 インチのUSBモニタに MPC-BE 音楽再生時の情報を表示させるためのツールです。

turing-smart-screen-python のライブラリを使っています。

https://github.com/mathoudebine/turing-smart-screen-python/tree/main


## 使い方
### MPC-BE は ウェブインタフェース を有効にする
ファイル → Option → プレーヤー → ウェブインタフェース
以下の2つの項目を有効にする
- 「待機するポート」
- 「ローカルホストからの接続のみ」

### TURZX は縦置きを想定

### 実行方法
pip install -r requirements.txt
python main.py

### その他
動作内容は以下の通りです。
1. MPC-BE のウェブサーバにアクセスして以下の情報を取得
   - 再生中のファイルのフルパス
   - 曲の長さ
   - 再生中の位置

2. ファイルのタグ情報から以下の情報取得
   - タイトル
   - アーティスト
   - アルバム
   - オーディオ情報
   - 画像情報

3. 画像情報がない場合は再生ファイルと同一ディレクトリに \*cover\*.png/jpg/jpeg, Folder.jpg, \*front\*.jpg の画像ファイルを検索

4. 3. で画像が検出されなかった場合は default_png 配下の画像からランダムに抽出
   
   現状含まれているファイルは AI で生成した画像となっています。
   - 落ち着いた雰囲気の風景画
   - 落ち着いた雰囲気の未来都市
   - 落ち着いた雰囲気の宇宙

5. 再生中のファイル名と同名のCUEファイルが存在した場合はその内容を表示
   
   MPC-BEでは UTF-8 の CUE ファイルしか対応していませんが、ShiftJISでも読み込めるようにしています。

6. 再生中のファイル名と同一ディレクトリまたは Lyrics というサブディレクトリ配下を検索し存在した場合は歌詞を表示
   
   複数言語の歌詞ファイルの場合は同一タイムスタンプにおいて最後の行が優先されます。

7. 各種情報を 3.5インチの画面に表示
   
   基本的には MPC-BE で音楽を再生しているイメージと似た雰囲気になります。
   
8. たまに画面表示がおかしくなる…
   
   アプリ終了時にデバイスにcloseSerial と resetを送っていますが、うまく反映されないことがあります。
   その状態でアプリを起動すると画面描画おかしくなりますが、アプリを再起動することで直ります。
